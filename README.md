# 🎬 SmartSync AI - Cloud Media Hub

**SmartSync AI** is a modern, full-stack SaaS web application built with **FastAPI** and **Tailwind CSS**. It allows users to download YouTube media, manage personalized libraries, and leverage AI-powered metadata extraction, all wrapped in a stunning "Cyber AI" glassmorphism interface.

## 🌟 Key Features

### 🆓 Free Tier

- **Secure Auth:** JWT-based login/signup with password strength validation.
- **Smart Organization:** Auto-sorts downloads into MP3/MP4 system folders.
- **Real-Time Tracking:** Glowing progress bars and desktop toast notifications.
- **Custom Themes:** Personalize the dashboard (Purple, Red, Green).
- **Daily Limits:** 5 downloads per day to encourage Pro upgrades.

### 💎 SmartSync Pro (Premium Tier)

- **🤖 AI Video Summary:** Instantly extracts and formats video descriptions into 3-bullet-point summaries.
- **📂 Playlist Downloader:** Paste a YouTube playlist URL to bulk-download entire playlists.
- **🎬 4K Ultra HD & 320kbps Audio:** Unlocked maximum quality media extraction.
- **❤️ Favorites System:** Save videos to a permanent, personalized watch-later list.
- **⚡ Unlimited Downloads:** No daily restrictions.

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI, SQLAlchemy (SQLite), `yt-dlp`
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (SSE for real-time progress)
- **Security:** JWT (JSON Web Tokens), Bcrypt password hashing, OAuth2
- **Architecture:** RESTful API with Server-Sent Events (SSE) for live progress tracking.
